# Detector Families

Included detector/guard families: max_step_guard, file_revisit_guard, exact_action_repeat, tool_repeat, tool_sequence_repeat, action_observation_repeat, error_signature_repeat, and repeat_without_progress_guard. These are common progress-insensitive guards plus a simple progress-aware contrast, not a SOTA detector claim. Detector features do not use PI/HN/UC labels.
